INTRODUCTION Cryptography & Network Security Lab

Elliptic Curve Cryptography (ECC) is a public-key cryptography technique that uses mathematical operations on elliptic curves to support secure communication. Elliptic Curve Diffie-Hellman (ECDH) is a key exchange mechanism based on ECC that allows two participants to establish a common shared secret over a public channel without directly sharing their private keys. This laboratory experiment demonstrates the basic mathematical operations and step-by-step process involved in ECDH key exchange.

AIM Primary Laboratory Aim
To study and demonstrate Elliptic Curve Cryptography (ECC) and the ECDH key exchange mechanism through a web-based laboratory experiment and verify that both participants independently calculate the same shared secret.

📖 Theory

Mathematical Foundations of Elliptic Curve Cryptography & ECDH Protocol

DEFINITIONS

1. Basic Concepts

  • ECC (Elliptic Curve Cryptography): A public-key cryptography technique based on elliptic curve mathematics.
  • ECDH (Elliptic Curve Diffie-Hellman): A method that allows two participants to calculate the same shared secret without directly sharing their private keys.
  • Elliptic Curve: A mathematical equation that defines the valid points used in ECC.
  • Finite Field: A mathematical system with a limited set of values where modulo arithmetic is performed.
  • Generator Point (G): A selected point used as the starting point for public-key calculations.
  • Private Key (k): A secret integer kept by each participant.
  • Public Key (Q): A point calculated using the private key and generator point.
  • Point Addition: Combines two different points on the curve to obtain another point.
  • Point Doubling: Adds a point to itself to obtain another point.
  • Scalar Multiplication: Multiplies a point by an integer using point addition and point doubling.
  • Shared Secret: A common point independently calculated by both participants.
  • ECDLP (Elliptic Curve Discrete Logarithm Problem): Recovering the private scalar from the generator point and public key is computationally difficult with suitable real-world parameters.
EQUATIONS

2. Important Formulas

Formula 1: Elliptic Curve Equation

\[y^2\equiv x^3+ax+b\pmod p\]

Symbols: \(x,y\) are point coordinates; \(a,b\) are curve parameters; \(p\) is the prime modulus.

Meaning: Defines the valid points on the elliptic curve.

Formula 2: Point Addition

For two different points \(P=(x_1,y_1)\) and \(Q=(x_2,y_2)\):

\[m=\frac{y_2-y_1}{x_2-x_1}\pmod p\] \[x_3=m^2-x_1-x_2\pmod p\] \[y_3=m(x_1-x_3)-y_1\pmod p\]

Symbols: \(m\) is the slope; \(x_1,y_1,x_2,y_2\) are input coordinates; \(x_3,y_3\) are output coordinates.

Meaning: Combines two different curve points to calculate a new point.

Formula 3: Point Doubling

For a point \(P=(x_1,y_1)\):

\[m=\frac{3x_1^2+a}{2y_1}\pmod p\] \[x_3=m^2-2x_1\pmod p\] \[y_3=m(x_1-x_3)-y_1\pmod p\]

Symbols: \(m\) is the tangent slope; \(a\) is a curve parameter; \(x_1,y_1\) are input coordinates; \(x_3,y_3\) are output coordinates.

Meaning: Adds a point to itself to calculate a new point.

Formula 4: Scalar Multiplication and Public-Key Generation

\[Q=kG\]

Symbols: \(Q\) is the public key; \(k\) is the private-key scalar; \(G\) is the generator point.

Meaning: Calculates a public key using the private key and generator point through point addition and doubling.

Formula 5: ECDH Shared Secret

\[A=aG,\qquad B=bG\] \[S_A=aB,\qquad S_B=bA\] \[S_A=S_B=abG\]

Symbols: \(a,b\) are Alice's and Bob's private keys; \(A,B\) are their public keys; \(G\) is the generator point; \(S_A,S_B\) are the shared secrets.

Meaning: Alice and Bob independently calculate the same shared secret.

📖 ECC & ECDH Concepts

Mathematical Foundations of Elliptic Curve Cryptography

01

What is Elliptic Curve Cryptography (ECC)?

ECC is an asymmetric public-key cryptosystem based on the algebraic structure of elliptic curves over finite fields. Its primary security relies on the Elliptic Curve Discrete Logarithm Problem (ECDLP): given a base point \(G\) and a public point \(P = k \cdot G\), it is computationally infeasible to determine the secret scalar \(k\).

Key Advantage: Equivalent security to RSA with significantly smaller keys (e.g. 256-bit ECC \(\approx\) 3072-bit RSA).
02

The Elliptic Curve Equation

In our simulator, we use the standard Weierstrass Equation over a prime finite field \(\mathbb{F}_p\):

\[y^2 \equiv x^3 + ax + b \pmod{p}\]

To ensure the curve has no cusps, self-intersections, or singular points, the discriminant must satisfy:

\[\Delta = 4a^3 + 27b^2 \not\equiv 0 \pmod{p}\]
03

What is a Finite Field (\(\mathbb{F}_p\))?

Instead of smooth, continuous real numbers \(\mathbb{R}\), finite field cryptography uses modular arithmetic over integers modulo a prime \(p\): \(\{0, 1, 2, \dots, p-1\}\).

Division in \(\mathbb{F}_p\) is accomplished by computing the modular multiplicative inverse using Fermat's Little Theorem or the Extended Euclidean Algorithm:

\[\frac{1}{d} \equiv d^{-1} \equiv d^{p-2} \pmod{p}\]
04

Point on a Curve & Point at Infinity

A point \(P = (x, y)\) is a valid point if its coordinates satisfy \((y^2 - (x^3 + ax + b)) \bmod p = 0\).

The curve also includes a special identity element called the Point at Infinity (\(\mathcal{O}\)), which acts like zero in regular addition:

\[P + \mathcal{O} = P \quad \text{and} \quad P + (-P) = \mathcal{O}\]
05

Point Addition (\(P + Q = R\), \(P \ne Q\))

To add two distinct points \(P = (x_1, y_1)\) and \(Q = (x_2, y_2)\) where \(x_1 \ne x_2\):

\[m = \frac{y_2 - y_1}{x_2 - x_1} \pmod{p}\] \[x_3 = (m^2 - x_1 - x_2) \pmod{p}\] \[y_3 = (m(x_1 - x_3) - y_1) \pmod{p}\]
06

Point Doubling (\(P + P = 2P\))

When adding a point to itself (\(P = Q\)), the slope is the tangent to the curve at \((x_1, y_1)\):

\[m = \frac{3x_1^2 + a}{2y_1} \pmod{p}\] \[x_3 = (m^2 - 2x_1) \pmod{p}\] \[y_3 = (m(x_1 - x_3) - y_1) \pmod{p}\]
07

Scalar Multiplication (\(k \cdot P\))

Scalar multiplication computes \(k \cdot P = \underbrace{P + P + \dots + P}_{k \text{ times}}\).

Using the Double-and-Add Algorithm (binary method), scalar multiplication runs in logarithmic \(O(\log k)\) steps instead of linear time: 

result = None
while k > 0:
    if k % 2 == 1:
        result = point_add(result, P)
    P = point_add(P, P)  # Point doubling
    k = k // 2
08

Elliptic Curve Diffie-Hellman (ECDH) Protocol

ECDH allows two parties (Alice and Bob) to establish a shared cryptographic key over an insecure public channel without transmitting the secret:

👩‍💻 Alice

Private Key: \(d_A\) (secret)

Public Key: \(A = d_A \cdot G\)

Sends \(A \to\) Bob
Calculates:
\[S_{\text{Alice}} = d_A \cdot B = d_A \cdot (d_B \cdot G)\]
Public Channel ⇄ Transmits \(A\) and \(B\)
\[d_A \cdot d_B \cdot G = d_B \cdot d_A \cdot G\] Shared Secret is Identical!

👨‍💻 Bob

Private Key: \(d_B\) (secret)

Public Key: \(B = d_B \cdot G\)

Sends \(B \to\) Alice
Calculates:
\[S_{\text{Bob}} = d_B \cdot A = d_B \cdot (d_A \cdot G)\]

📊 Result & Conclusion

Laboratory Findings, Working Principles & Key Exchange Verification

🎓
Conclusion

Conclusion

  • ECC is a public-key cryptography technique that uses elliptic curve mathematics.
  • ECDH allows two participants to establish the same shared secret without directly exchanging their private keys.
  • Public keys are generated using private keys and a common generator point.
  • Both participants calculate the same shared secret using their own private keys and each other's public keys.
  • The shared secret can be used with an appropriate key-derivation process to obtain a symmetric encryption key.
Limitation

⚠️ Limitations

Man-in-the-Middle Attack: ECDH alone does not verify participant identities, so an attacker may intercept and replace public keys unless suitable authentication is used.
