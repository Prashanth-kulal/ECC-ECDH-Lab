📖 ECC & ECDH Concepts

Mathematical Foundations of Elliptic Curve Cryptography

01

What is Elliptic Curve Cryptography (ECC)?

ECC is an asymmetric public-key cryptosystem based on the algebraic structure of elliptic curves over finite fields. Its primary security relies on the Elliptic Curve Discrete Logarithm Problem (ECDLP): given a base point \(G\) and a public point \(P = k \cdot G\), it is computationally infeasible to determine the secret scalar \(k\).

Key Advantage: Equivalent security to RSA with significantly smaller keys (e.g. 256-bit ECC \(\approx\) 3072-bit RSA).
02

The Elliptic Curve Equation

In our simulator, we use the standard Weierstrass Equation over a prime finite field \(\mathbb{F}_p\):

\[y^2 \equiv x^3 + ax + b \pmod{p}\]

To ensure the curve has no cusps, self-intersections, or singular points, the discriminant must satisfy:

\[\Delta = 4a^3 + 27b^2 \not\equiv 0 \pmod{p}\]
03

What is a Finite Field (\(\mathbb{F}_p\))?

Instead of smooth, continuous real numbers \(\mathbb{R}\), finite field cryptography uses modular arithmetic over integers modulo a prime \(p\): \(\{0, 1, 2, \dots, p-1\}\).

Division in \(\mathbb{F}_p\) is accomplished by computing the modular multiplicative inverse using Fermat's Little Theorem or the Extended Euclidean Algorithm:

\[\frac{1}{d} \equiv d^{-1} \equiv d^{p-2} \pmod{p}\]
04

Point on a Curve & Point at Infinity

A point \(P = (x, y)\) is a valid point if its coordinates satisfy \((y^2 - (x^3 + ax + b)) \bmod p = 0\).

The curve also includes a special identity element called the Point at Infinity (\(\mathcal{O}\)), which acts like zero in regular addition:

\[P + \mathcal{O} = P \quad \text{and} \quad P + (-P) = \mathcal{O}\]
05

Point Addition (\(P + Q = R\), \(P \ne Q\))

To add two distinct points \(P = (x_1, y_1)\) and \(Q = (x_2, y_2)\) where \(x_1 \ne x_2\):

\[m = \frac{y_2 - y_1}{x_2 - x_1} \pmod{p}\] \[x_3 = (m^2 - x_1 - x_2) \pmod{p}\] \[y_3 = (m(x_1 - x_3) - y_1) \pmod{p}\]
06

Point Doubling (\(P + P = 2P\))

When adding a point to itself (\(P = Q\)), the slope is the tangent to the curve at \((x_1, y_1)\):

\[m = \frac{3x_1^2 + a}{2y_1} \pmod{p}\] \[x_3 = (m^2 - 2x_1) \pmod{p}\] \[y_3 = (m(x_1 - x_3) - y_1) \pmod{p}\]
07

Scalar Multiplication (\(k \cdot P\))

Scalar multiplication computes \(k \cdot P = \underbrace{P + P + \dots + P}_{k \text{ times}}\).

Using the Double-and-Add Algorithm (binary method), scalar multiplication runs in logarithmic \(O(\log k)\) steps instead of linear time: 

result = None
while k > 0:
    if k % 2 == 1:
        result = point_add(result, P)
    P = point_add(P, P)  # Point doubling
    k = k // 2
08

Elliptic Curve Diffie-Hellman (ECDH) Protocol

ECDH allows two parties (Alice and Bob) to establish a shared cryptographic key over an insecure public channel without transmitting the secret:

👩‍💻 Alice

Private Key: \(d_A\) (secret)

Public Key: \(A = d_A \cdot G\)

Sends \(A \to\) Bob
Calculates:
\[S_{\text{Alice}} = d_A \cdot B = d_A \cdot (d_B \cdot G)\]
Public Channel ⇄ Transmits \(A\) and \(B\)
\[d_A \cdot d_B \cdot G = d_B \cdot d_A \cdot G\] Shared Secret is Identical!

👨‍💻 Bob

Private Key: \(d_B\) (secret)

Public Key: \(B = d_B \cdot G\)

Sends \(B \to\) Alice
Calculates:
\[S_{\text{Bob}} = d_B \cdot A = d_B \cdot (d_A \cdot G)\]
